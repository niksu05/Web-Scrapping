# Task 1 — Inspect a Flipkart Product Title

## Objective
Identify the HTML tag and class name for a product title using Chrome Developer Tools.

## Steps
1. Open Flipkart in Chrome.
2. Right-click a product title and choose **Inspect**.
3. In the **Elements** panel, locate the element containing the title.
4. Note the tag and class attribute.

## Observation
In my inspection screenshot, the product title was inside a `div` element with class `RG5SIk`.

- **HTML tag:** `div`
- **Class name:** `RG5SIk`

Example based on the inspected page (the title and class may change when Flipkart updates its website):

```html
<div class="RG5SIk">HP 15 Intel Core 5 120U ...</div>
```

## What I learned
Developer Tools helps me inspect a webpage's HTML and identify elements that may contain information for scraping.
