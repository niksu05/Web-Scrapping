# Web Scraping — Session 1: Introduction

## Overview
This session introduces web scraping, robots.txt rules, static and dynamic content, and using browser Developer Tools to inspect HTML and HTTP requests.

## Tasks
1. **Flipkart:** Inspect a product listing and identify the HTML tag and class used for its title.
2. **Zomato robots.txt:** List two rules and explain what they mean.
3. **Myntra vs Instagram:** Compare how page content loads.
4. **BookMyShow:** Find the `User-Agent` request header in DevTools and explain it.

## What I learned
- Inspect HTML tags and CSS classes using Developer Tools.
- Read robots.txt rules for web crawlers.
- Understand the difference between initial HTML and dynamically fetched content.
- Inspect HTTP request headers in the Network tab.

## Note
Website HTML and robots.txt rules can change. Follow each website's terms and access rules; do not bypass restrictions.
